11. IMPORTANT NOTES
═══════════════════════════════════════

- ALWAYS run "docker-compose down" before "docker-compose up -d" when
  rebuilding images. Skipping this causes a "ContainerConfig" error.

- Never run "docker-compose up -d --build" directly — same bug.

- DB data is stored in a Docker volume (postgres_data) — it survives
  container restarts and "docker-compose down". Only "docker-compose down -v"
  would delete it (NEVER run that on production).

- The .env file is at ~/kau-fpo-backend/.env — edit it directly on the
  server for any config changes, then restart the affected containers.
